# Reports Index

- `reports/task1/`: Task 1 mini report, data, and figures
- `reports/task2/`: Task 2 mini report, data, and figures
- `reports/task3/`: Task 3 mini report, data, and figures
- `reports/task4/`: Task 4 mini report, data, and figures
- `reports/final/`: Combined final report for Task 1~4

## Report language rule

From now on, each task report should be provided in **both Chinese and English**.

Recommended files inside each task folder:

- `report.md` or `report.zh.md`: Chinese version
- `report.en.md`: English version
- `data/`
- `figures/`

Recommended files inside `reports/final/`:

- `report.md`: Chinese combined report
- `report.en.md`: English combined report

Keep the same section order in both language versions so that they can be compared and maintained easily.
